# صدرا AI (Sadra AI)

## وضعیت واقعی این بسته
این پروژه یک برنامه‌ی Android با Kotlin و Jetpack Compose است. امکانات فعلی شامل رابط فارسی RTL، تاریخچه‌ی محلی Room، تشخیص گفتار و تبدیل متن به گفتار اندروید، فراخوانی رسمی دستیار سیستم، اجرای تعدادی دستور دستگاه، آلارم/تایمر، کنترل رسانه و کنترل صدای رسانه است.

**مهم: این نسخه هنوز یک دستیار هوش مصنوعی مولد کامل نیست.** فایل ZIP اولیه هیچ مدل زبانی محلی، موتور inference اندرویدی، فایل وزن مدل یا مدل‌منیجر نداشت. برای جلوگیری از ادعای دروغین و ارسال گفتگو به سرویس ابری، مسیر گفت‌وگوی آزاد به‌جای فراخوانی API اکنون پیام روشن می‌دهد که مدل محلی نصب نشده است. دستورهای شناخته‌شده‌ی آفلاین همچنان توسط parser اجرا می‌شوند.

## الزامات ساخت
- Android Studio با JDK 17
- Android SDK با API 34 (compileSdk 34)
- Gradle wrapper distribution: Gradle 8.7
- حداقل Android 8.0 / API 26

این محیط تحویل فاقد Android SDK، Gradle wrapper JAR و ابزار adb بود؛ بنابراین APK/AAB ساخته یا روی دستگاه آزمایش نشده است. ادعای build موفق یا تست فیزیکی وجود ندارد.

## ساخت در Android Studio
1. ZIP را استخراج کنید.
2. پوشه‌ی `SadraAI` را در Android Studio باز کنید.
3. اجازه دهید Gradle Sync کامل شود و SDK 34 را نصب کنید.
4. برای اجرای نسخه‌ی آزمایشی از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
5. فایل APK را از مسیر `app/build/outputs/apk/debug/` بردارید.

## دستورهای آفلاین پیاده‌سازی‌شده
- باز کردن تعدادی از برنامه‌های شناخته‌شده و تنظیمات
- باز کردن صفحه‌ی تنظیمات Wi-Fi (نه روشن/خاموش کردن مستقیم Wi-Fi)
- تنظیم آلارم و تایمر با Intent رسمی
- زیاد/کم کردن صدای رسانه و تنظیم درصد دقیق ۰ تا ۱۰۰
- ارسال فرمان‌های play/pause/next/previous به برنامه‌ی رسانه
- جستجوی وب با Intent مرورگر/جستجو
- اعلام ساعت محلی

## قابلیت‌هایی که هنوز کامل نیستند
- مدل زبانی محلی و دانلود/اعتبارسنجی مدل: پیاده‌سازی نشده
- پاسخ‌گویی آزاد فارسی/انگلیسی، خلاصه‌سازی حافظه و مکالمه‌ی هوشمند: وابسته به مدل محلی آینده
- گفتار فارسی آفلاین: به موتور گفتار نصب‌شده و پشتیبانی دستگاه وابسته است؛ تضمین نمی‌شود
- اجرای دستیار با کلید کناری: به نسخه‌ی Android و سازنده وابسته است
- پخش مستقیم فایل‌های محلی با MediaStore و MediaSession کامل: هنوز پیاده‌سازی نشده؛ کنترل رسانه از طریق کلیدهای استاندارد سیستم است
- تغییر مستقیم وضعیت Wi-Fi: توسط Android برای برنامه‌ی عادی محدود شده است
- overlay، VoiceInteraction و جریان مجوزها: نیازمند تست روی گوشی واقعی و سازندگان مختلف
- تاریخچه‌ی محلی Room رمزگذاری سرتاسری نشده است
- تغییر نام گفتگو و مدیریت جداگانه‌ی حافظه‌ی بلندمدت: هنوز وجود ندارد
- آزمون‌های واحد در این محیط اجرا نشده‌اند.

## حریم خصوصی و شبکه
- `AiClient` هیچ درخواست شبکه‌ای ارسال نمی‌کند و تاریخچه‌ی گفتگو را به هیچ AI API نمی‌فرستد.
- مجوز INTERNET همچنان برای سازگاری اجزای دیگر پروژه و احتمالاً تأیید خرید مایکت باقی مانده است؛ وجود این مجوز به معنی ارسال گفتگو نیست.
- `SADRA_BACKEND_URL` در `gradle.properties` فقط برای endpoint اختیاری تأیید خرید استفاده می‌شود، نه استنتاج AI. سرور backend اولیه‌ی وابسته به Anthropic از این بسته حذف شده است.
- STT ممکن است توسط سرویس تشخیص گفتار نصب‌شده پردازش شود؛ رفتار آفلاین/آنلاین آن تابع دستگاه است.
